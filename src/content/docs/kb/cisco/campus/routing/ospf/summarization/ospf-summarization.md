## External Route Summarization (E1,E2)
The ASBR is the only router that can modify, change, or hide information on its Type-5 external LSAs. s such, the ASBR is the only place in the OSPF network where external prefix summarization is available. the summary-address command was introduced especially for this purpose. When configured, the ASBR will not create a Type-5 LSA for all of the external prefixes that fall within the range indicated in the summary-address command. Instead, it will advertise the indicated summary prefix.

## Summary Null Router
The strange thing about the routes is that they have an exit interface of Null0. This is called the discard interface on Cisco routers. Such routes assigned to the Null0 discard interface are called discard routes. 

1. On any router 
    - Use the command no discard-route
    - Modify the administrative distance for discard routes to 255 
2. If the router is an ABR 
    - Use the command no discard-route internal command
3. If the router is an ASBR 
    - Use the command no discard-route external command
    - Modify the administrative distance of the null 0 route to 255 with the discard-route external 255 command. This prevents the route from being installed into the routing table 
All methods make use of the discard-route command in Cisco IOS configuration. This command controls whether or not the discard route is created and with what AD value the discard route will have. if configured with the internal keyword, the command only affects discard routes generated for internal routes. If configured with the external keyword, the command only affects discard routes generated for external routes. Thus, use of the internal command is designed for ABRs and the external command ASBRs. If used without either the internal or external keywords, the command affects all OSPF discard routes generated by the router.
