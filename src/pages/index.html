Labdex

U2 · tool · homelab inventory

A small inventory for homelabs. NetBox is a lot to learn and run for a lab, so I wrote something lighter. You describe the lab once and Labdex generates DNS records, firewall aliases and an Ansible inventory. It runs in one container with SQLite and under 100 MB of RAM, and I use it in my own lab.

zonesTrust zones and naming rules, linted
opnsenseFirewall aliases, synced
dnsA, AAAA, CNAME and SRV records
ansibleInventory, plan first, then apply
