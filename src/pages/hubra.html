Hubra

Club software for Swiss clubs, with members, fees, events, votes and groups in one app. Members only need a browser.

Visit hubra.club {{icon:ext}}
Hosted in EuropeNo tracking, no adsGerman & EnglishStarted at VollBuildNot open to other clubs yet

Features

Members

Applications, membership tiers, offices and a member directory each member opts into.

Finance

Fee schedules, Swiss QR bills, automatic reminders and payment matching from a camt.054 bank file.

Events and training

Recurring sessions, sign-ups, guests and attendance with one tap, plus push reminders.

Polls and votes

Vote online, by proxy too, for all members or just one group.

Security

Passkeys, hosting in Europe, a key per club and encrypted backups.

Plugins

Payments, bookings, inventory, documents, keys, a till, a Discord bridge and more, from the plugin catalogue.

Background

Why I built it

I wanted club software that looks good, has the features I need, and is cheap enough that small clubs can afford it.

It started for VollBuild, the makerspace club I'm part of, and grew from there. Hubra isn't public or in production yet, and no other clubs are on it so far.

Hubra is closed source. The code is on GitHub because I use it for automation and infrastructure as code.
